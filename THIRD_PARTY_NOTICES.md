The encoder is fetched separately by `scripts/bootstrap.ps1`. Its sources, model and binaries are not committed to this repository. The native CMake target builds only the encoder with its original 16-channel capacity. A Windows spelling shim for `strcasecmp` is supplied; decoder code is neither built nor patched.

Cavern is fetched separately by `scripts/build-cavern.ps1` and compiled from the pinned clean checkout. Portable builds bundle its two assemblies, the original licence, and the original wrapper with a self-contained .NET runtime. The application names Cavern and links to its creator. No Truehdd binary, FFmpeg, Dolby SDK, or JOC encoder is bundled for this import path. Cavern can approximate sparse JOC reconstruction; the exporter records `sparse_workaround` in its report. Reconstructed JOC objects are not the original ADM master objects.

The Rust decoder used for independent local verification is [1254qwer/avs3a-rust](https://github.com/1254qwer/avs3a-rust), commit `59213e47a27ffa6ba9211bac1f5a6c6fd182e9d8`. It is not a runtime dependency and is not bundled.
